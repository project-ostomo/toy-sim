# Scattered 2,000-player benchmark — 2026-09-23

Release build on the Ryzen 5 3600XT. One repetition, one warmup tick,
five measured ticks; static BVH rebuilt each tick, sparse scene, account-cache
fix included. Measures simulation and publication including snapshot serialization,
excluding client rendering and network transport. Diagnostic scopes are enabled.

Player ships occupy 2,000 distinct catalogue systems, shuffled with ChaCha8 seed
`0x5343415454455231`. Each starts at max(1 AU, four primary radii) from its primary,
with local circular-orbit velocity plus the primary's velocity. Background ships
retain their normal placement. Normal simulation activates the occupied systems.

There were 2,000 sensor scans and 2,000 range results per tick (self only),
zero selected contacts, and therefore zero sensor occlusion rays. This is a
widely dispersed population measurement; it does not measure crowded combat or
occlusion-ray throughput.

Final population: 4,997 occupied systems, 78,629 spatial records including
73,628 celestials, and 5,001 collision bodies. No collision groups or contact
pairs formed. Setup took 4.781 seconds; the excluded warmup tick took about
13.662 seconds including publication (its simulation took 1.412 seconds).

## Historical comparison

The previous post-cache-fix line fixture averaged 4,181.4967 ms/tick:
98.8886 ms simulation plus 4,082.6081 ms publication. This scattered fixture is
60.1% lower overall (2.50 times the throughput), with simulation 40.0% higher
and publication 62.5% lower. Previous sensor segment queries alone took
2,740.8707 ms/tick; the new fixture issues no such rays.

This comparison changes spatial distribution and active celestial population.
It is not evidence of a BVH implementation speedup. Five early ticks after one
warmup provide a short sample, not a long-run steady-state estimate.

## Reproduction

```sh
cargo test --offline --release -p osg-server --lib --no-run
env -u OSG_BENCH_SPATIAL_CAPTURE -u OSG_BVH_PROFILE -u OSG_SPATIAL_PROFILE \
  OSG_BENCH_BVH=static OSG_BENCH_PLAYERS=2000 OSG_BENCH_REPEATS=1 \
  OSG_BENCH_FRAMES=5 OSG_BENCH_WARMUP=1 OSG_BENCH_SCENE=sparse \
  target/release/deps/osg_server-505a05606d0c1953 \
  sim::benchmark::production_tick_and_publication \
  --ignored --exact --nocapture --test-threads=1
```

The test passed. Binary and selected source hashes are in
[sha256.txt](scattered-2000-2026-09-23/sha256.txt).
